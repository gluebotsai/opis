# Brand \& Design System Context

This project uses a strict design token system exported from Figma. Always use these exact values — never invent colors, sizes, or spacing.

\---

## Font

* Family: **Inter**
* Weights: Regular | Medium | Semi Bold
* Sizes: 10 / 12 / 14 / 16 / 18 / 20px
* Line heights: 16 / 20 / 24 / 28px

## Brand Color

* **Primary accent (Violet):** `#7423D7`
* Hover: `#8650DE` | Active/Focus: `#5F1FB0` | Dark: `#431A7E`

## Semantic Colors — Use these in all UI, not raw hex

### Text

* Primary: `#0B0B10` | Secondary: `#3F3F49` | Caption: `#5E5E69`
* Placeholder: `#7E7E88` | On-dark: `#FFFFFF` | On-dark muted: `#A7A7AF`
* Success: `#0E8F50` | Info: `#1869D3` | Warning: `#866300` | Caution: `#874400` | Danger: `#C73E32`

### Backgrounds

* Canvas: `#F4F4F6` | Surface / cards: `#FFFFFF` | Subtle (inside white): `#F4F4F6`
* Canvas inverse: `#0B0B10` | Subtle inverse: `#23232B`
* Success bg: `#F6FBF9` | Info bg: `#F9FBFE` | Warning bg: `#FFFEFA` | Caution bg: `#FEFBF9` | Danger bg: `#FFFAFB`

### Borders

* Default: `#C9C9CF` | Strong: `#23232B` | Focus ring: `#5F1FB0`
* Success: `#0F9D58` | Info: `#1A73E8` | Warning: `#F4B400` | Caution: `#F57C00` | Danger: `#DB4437`

### States

* Hover: `#E2E2E6` | Active: `#C9C9CF` | Pressed: `#23232B`
* Disabled bg: `#E2E2E6` | Disabled text: `#7E7E88`

### Icons

* On light: `#23232B` | On dark: `#C9C9CF` | Disabled: `#A7A7AF`

## Spacing

* Gap: 4 / 8 / 16 / 24 / 32px
* Padding: 2 / 4 / 8 / 16px
* Border radius: 4 / 8 / 12 / 16 / 32px / 9999px (pill)
* Border width: 0.6px (hairline) / 2px (standard)
* Button horizontal padding: 24px

## Max Widths

* 40 / 48 / 144 / 376 / 608 / 798px

## Buttons

* Radius: 12px | Font: 14px regular / 16px large
* **Primary:** bg `#0B0B10` text `#FFFFFF` → hover `#3F3F49`
* **Alt (brand):** bg `#7423D7` text `#FFFFFF` → hover `#8650DE`
* **Secondary:** bg `#FFFFFF` text `#0B0B10` border `#C9C9CF` → hover border `#23232B`
* **Tertiary:** transparent text `#0B0B10` → hover text+icon `#7423D7`
* **Link:** text `#7423D7`
* **Disabled:** bg `#E2E2E6` text `#A7A7AF`
