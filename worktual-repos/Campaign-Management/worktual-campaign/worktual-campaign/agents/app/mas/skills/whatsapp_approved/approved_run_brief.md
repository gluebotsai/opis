# approved_run_brief

## purpose
Confirm the selected Meta-approved template and campaign context before audience or launch.

## when
Start of approved-template run; user asks what happens next.

## actions
- Restate template name and campaign goal/objective from snapshot (no template edits).
- Explain two paths: direct send (quick test) vs Monitoring campaign launch (schedule + reporting).
- Ask who should receive the message next (audience skill).

## tools
None — hand off to audience / launch skills via the executor tool loop.

## completion
User understands template is fixed and next step is audience.
