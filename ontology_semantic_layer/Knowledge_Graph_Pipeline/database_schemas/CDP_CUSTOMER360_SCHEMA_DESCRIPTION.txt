CDP CUSTOMER 360 SCHEMA DESCRIPTION
===================================

Reference source: cdp_schema_new.sql
Schema: cdp
Default owner: nlp
Tenancy key: organization_id BIGINT

Notation
--------
PK       Primary key
FK       Foreign key
UQ       Unique constraint/index
NN       NOT NULL
RLS      Row-level security
JSONB    Flexible structured JSON data

General tenancy and security
----------------------------
Most Customer 360 tables contain organization_id BIGINT NN.
Most tables are configured with FORCE ROW LEVEL SECURITY.
Declared tenant policies compare organization_id with:
current_setting('app.current_org_id')::bigint.
The internal agentic_model scheduler table intentionally has RLS disabled because
its worker claims model jobs across organizations.


1. cdp.source_systems
---------------------
Purpose: Registry of external systems that contribute Customer 360 data.

Columns:
- source_id UUID NN, default gen_random_uuid(): Internal source identifier.
- source_name VARCHAR(255) NN: Organization-scoped source name.
- source_type VARCHAR(128) NN: Connector/source category.
- active BOOLEAN NN, default TRUE: Whether ingestion from the source is enabled.
- created_at TIMESTAMPTZ NN, default NOW(): Registration timestamp.
- organization_id BIGINT NN: Owning organization.
- custom_fields JSONB NN, default {}: Source-specific extension attributes.

Constraints:
- PK: source_id.
- UQ: (organization_id, source_name).

Indexes:
- idx_source_systems_org (organization_id).

Security:
- FORCE RLS.


2. cdp.customer_profile
-----------------------
Purpose: Golden Customer 360 profile; parent record for customer-linked data.

Columns:
- cdp_id UUID NN, default gen_random_uuid(): Canonical customer identifier.
- first_name VARCHAR(128): Customer first name.
- last_name VARCHAR(128): Customer last name.
- gender VARCHAR(32): Customer gender when supplied.
- date_of_birth DATE: Customer birth date.
- company VARCHAR(255): Company or employer.
- city VARCHAR(128): Customer city.
- region VARCHAR(128): State, province, or region.
- country VARCHAR(128): Customer country.
- language VARCHAR(64): Preferred language.
- timezone VARCHAR(64): Customer timezone.
- acquisition_channel VARCHAR(128): Initial acquisition channel.
- acquisition_date DATE: Acquisition date.
- first_referrer TEXT: First known referrer.
- first_seen_at TIMESTAMPTZ: First observed activity time.
- last_seen_at TIMESTAMPTZ: Most recent observed activity time.
- created_at TIMESTAMPTZ NN, default NOW(): Profile creation time.
- updated_at TIMESTAMPTZ NN, default NOW(): Last profile update time.
- organization_id BIGINT NN: Owning organization.
- custom_fields JSONB NN, default {}: Client/industry-specific profile fields.

Constraints:
- PK: cdp_id.

Indexes:
- idx_customer_profile_org (organization_id).
- idx_customer_profile_last_seen (organization_id, last_seen_at DESC).
- idx_customer_profile_custom_fields GIN (custom_fields).

Triggers:
- trg_customer_profile_updated_at automatically refreshes updated_at.

Security:
- FORCE RLS.
- Policy tenant_isolation_customer_profile scopes reads/writes by organization_id.


3. cdp.identity_keys
--------------------
Purpose: Maps emails, phones, source IDs, and other identities to a canonical customer.

Columns:
- identity_id UUID NN, default gen_random_uuid(): Identity-key record identifier.
- cdp_id UUID NN: Canonical customer receiving the identity.
- key_type VARCHAR(64) NN: Identity kind, such as email, phone, or source_customer_id.
- key_value VARCHAR(255) NN: Normalized identity value.
- source_system VARCHAR(255): Source that supplied the identity.
- confidence_score NUMERIC(5,4): Identity match confidence from 0 to 1.
- verified BOOLEAN NN, default FALSE: Whether the identity was verified.
- created_at TIMESTAMPTZ NN, default NOW(): Identity creation time.
- organization_id BIGINT NN: Owning organization.
- custom_fields JSONB NN, default {}: Identity-specific metadata.

Constraints:
- PK: identity_id.
- FK: cdp_id -> customer_profile.cdp_id, ON DELETE CASCADE.
- CHECK: confidence_score is NULL or between 0 and 1.
- UQ index: (organization_id, key_type, key_value), ensuring one canonical
  customer mapping per organization and identity.

Indexes:
- idx_identity_keys_unique (organization_id, key_type, key_value), UNIQUE.
- idx_identity_keys_cdp (cdp_id).
- idx_identity_keys_org (organization_id).

Security:
- FORCE RLS.


4. cdp.customer_events
----------------------
Purpose: Time-series behavioral and commerce events for each customer.
Partitioning: RANGE by occurred_at.

Columns:
- event_id UUID NN, default gen_random_uuid(): Event identifier.
- cdp_id UUID NN: Customer associated with the event.
- event_name VARCHAR(255) NN: Canonical event name.
- event_category VARCHAR(128): Event category.
- source_name VARCHAR(255): Originating source.
- source_event_id VARCHAR(255): Source-native event identifier.
- channel VARCHAR(64): Web, mobile, email, store, API, etc.
- visitor_id VARCHAR(128): Anonymous visitor identifier.
- session_id VARCHAR(128): Session identifier.
- page_path TEXT: Page or route where the event occurred.
- page_title VARCHAR(512): Page title.
- referrer TEXT: Event referrer.
- utm_source VARCHAR(128): UTM source.
- utm_medium VARCHAR(128): UTM medium.
- utm_campaign VARCHAR(128): UTM campaign.
- utm_term VARCHAR(255): UTM term.
- utm_content TEXT: UTM content.
- device_type VARCHAR(64): Device class.
- browser VARCHAR(128): Browser name/version.
- country VARCHAR(128): Event country.
- occurred_at TIMESTAMPTZ NN: Business occurrence time and partition key.
- ingested_at TIMESTAMPTZ NN, default NOW(): CDP ingestion time.
- amount NUMERIC(14,2): Monetary amount.
- currency VARCHAR(8): Currency code.
- quantity INTEGER: Associated quantity.
- status VARCHAR(64): Event/business status.
- reference_id VARCHAR(255): Related order, product, campaign, or external ID.
- properties_json JSONB NN, default {}: Canonical event properties.
- raw_payload_json JSONB NN, default {}: Original source payload.
- organization_id BIGINT NN: Owning organization.
- custom_fields JSONB NN, default {}: Client-specific event attributes.

Constraints:
- PK: (event_id, occurred_at); partition key is included.
- FK: cdp_id -> customer_profile.cdp_id, ON DELETE CASCADE.

Indexes:
- idx_customer_events_org_cdp_time
  (organization_id, cdp_id, occurred_at DESC).
- idx_customer_events_custom_fields GIN (custom_fields).
- idx_customer_events_visitor (visitor_id), only when visitor_id is not NULL.

Partitions:
- customer_events_2026_07: 2026-07-01 through 2026-08-01.
- customer_events_2026_08: 2026-08-01 through 2026-09-01.
- customer_events_default: catches dates outside explicit partitions.

Security:
- FORCE RLS on the partitioned parent.

Partition maintenance

Important reference observations
--------------------------------
1. The source numbering skips some labels, but this document numbers the 25
   actual parent/business tables sequentially.
2. idx_orders_unique_num is named as though it were unique, but the SQL defines
   a normal non-unique index.
3. FORCE RLS appears on many tables, while explicit CREATE POLICY statements
   are present only for selected tables in this reference. Deployment should
   verify policies for every FORCE-RLS table.
4. organization_id is BIGINT in the reference schema. Existing UUID databases
   require an explicit data migration; CREATE TABLE IF NOT EXISTS will not
   change old column types.
5. The agentic_model definition above reflects the current reference file,
   including operational lifecycle fields.
