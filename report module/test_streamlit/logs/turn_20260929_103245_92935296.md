## query understanding & intent resolution

Before formulating a plan, resolve the user's question into precise operational concepts:

### 1. Channel & Conversation Semantics
- **Conversations**: Omnichannel interaction sessions (`rpt.conversations`, `rpt.conversation_facts`). Channels include `voice`, `chat`, `whatsapp`, `email`, `sms`, `video`.
- **Calls (Telephony CDR)**: Raw telephony detail records (`rpt.calls`) with `recording_duration_seconds`, `hold_duration_seconds`, `call_duration_seconds`, `customer_number`, `agent_ext`.
- **Bot Sessions & Turns**: Self-service automated AI turns (`rpt.bot_turns`) with `intent`, `confidence`, `skill_key`, `grounded`, `guard_passed`, `handoff_recommended`.
- **Copilot / Agent Assist**: Real-time agent assist turns (`rpt.copilot_turns`) with `turn_type`, `skill_key`, `accepted`, `latency_ms`.

### 2. Status & Lifecycle Semantics
- **"Active conversations"**: Contacts currently in flight -> `status IN ('bot_active', 'queued', 'assigned', 'active')` (or `is_active = true`).
- **"Generic pending / Unresolved / Outstanding"**: Any conversation not yet finished -> `status NOT IN ('resolved', 'closed')` (or `is_resolved_or_closed = false`).
- **"Queued"**: Waiting in queue for an available agent -> `status = 'queued'`.
- **"Assigned / In Progress"**: Picked up by an agent -> `status IN ('assigned', 'active')`.
- **"Resolved"**: Successfully handled -> `status = 'resolved'` (or `is_resolved = true`).
- **"Closed"**: Terminated session -> `status = 'closed'` (or `is_closed = true`).
- **"Abandoned"**: Customer hung up or left before reaching an agent -> `is_abandoned = true`.
- **"Reopened"**: Customer re-contacted after resolution -> `is_reopened = true`.

### 3. Contact Center Core Operational Concepts
- **ASA (Average Speed to Answer)**: Queue wait time until agent pickup (`avg_speed_to_answer`).
- **AHT (Average Handle Time)**: Agent active talk/chat duration plus After Contact Work (ACW) (`avg_handle_time`, `avg_handle_time_voice`).
- **FCR (First Contact Resolution)**: Conversations resolved without reopen, escalation, or transfer (`fcr_rate`).
- **Containment**: Contacts fully resolved by the bot without human agent handoff (`bot_containment_rate`).
- **Occupancy**: Ratio of active handling time to total logged-in time (`agent_occupancy`).
- **SLA Breach**: Conversations missing first-response or resolution deadlines (`sla_breach_rate`).

### 4. People & Organization Lookups
- **Agents**: `agent_name`, `assigned_agent_id` on conversations, assignments, and presence.
- **Queues**: `queue_name`, `queue_id`.
- **Teams**: `team_name`, `team_id`.
- **Customers**: `contact_id`, `customer_number`.
